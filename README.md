# Saudi Healthcare Capacity & Performance Analytics 2021–2024

End-to-end healthcare analytics portfolio project built using official
Saudi Ministry of Health statistical yearbook data.

## Objective

Analyze healthcare capacity, resources, workforce, and healthcare
activities across Saudi Arabia from 2021 to 2024.

## Technology Stack

- Python
- SQL
- Power Query
- Power BI
- DAX
- Git / GitHub

## Project Status

Current Phase: SQL Foundation / Star Schema

## Data Source

Official Saudi Ministry of Health Statistical Yearbooks, 2021–2024.

Raw source files are preserved unchanged in the local `row_data` folder.

## Analytical Workflow

Business Problem
→ Data Discovery
→ Grain & Keys
→ Data Quality
→ Canonical Data
→ SQL Foundation
→ KPI Contracts
→ Validation
→ Python EDA
→ Power BI Semantic Model
→ Dashboard
→ Portfolio Publication
