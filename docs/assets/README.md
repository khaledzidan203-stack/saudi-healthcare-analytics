# Presentation Assets

This directory contains presentation-only visual assets for the Saudi Healthcare Analytics project.

## Current overview

`saudi-healthcare-analytics-overview.svg`

This is the evidence-aligned project overview used by the main README. It summarizes only repository-supported facts:

- 2021–2024 official Saudi MOH statistical yearbooks;
- nine canonical tables: four facts + five dimensions;
- SQL Server `analytics` schema as the reporting engine;
- ten semantic tables, 14 active relationships and 15 current measures;
- seven report pages and 121 saved visuals;
- 12/12 original governed DAX runtime checks PASS;
- 24/24 FY006 ↔ FY008 workforce reconciliation checks PASS;
- aggregate public statistics only; no patient-level data.

Presentation assets are not analytical source data, validation evidence, Power BI screenshots, or replacements for the governed contracts and release records. Authoritative claims are mapped in [`../PROJECT_EVIDENCE_MAP.md`](../PROJECT_EVIDENCE_MAP.md).
