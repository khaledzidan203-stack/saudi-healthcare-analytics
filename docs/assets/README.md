# Presentation Assets

This directory contains presentation-only visual assets for the Saudi Healthcare Analytics project.

## Current overview

`Saudi Healthcare Analytics Pipeline Infographic.png`

This is the project overview image used by the main README. It visually summarizes the implemented analytical path from official Saudi MOH statistical yearbooks through Python discovery, governed canonical modeling, SQL Server, Power BI, reporting, and validation.

The image is a presentation asset only. It is not analytical source data, validation evidence, a Power BI screenshot, or a replacement for the governed contracts and release records. Authoritative project claims remain defined by the canonical data, SQL/Power BI source, screenshots, contracts, and validation evidence mapped in [`../PROJECT_EVIDENCE_MAP.md`](../PROJECT_EVIDENCE_MAP.md).
